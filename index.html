💬 FEEDBACK
  1. Office Suite
    e-Office ല്‍ ഡ്രാഫ്റ്റുകൾ തയ്യാറാക്കുന്നതിനായിട്ടാണ് ഈ Application വികസിപ്പിച്ചിരിക്കുന്നത്.
  2. പ്രത്യേകതകൾ
    Alignment തെറ്റാതെ ഡ്രാഫ്റ്റുകൾ തയ്യാറാക്കാം, Mail Merge, Direct Copy Paste from the uploaded excel file.
  3. Bookmark
    Web Application തുറന്ന ഉടനെ Link bookmark ചെയ്ത് സൂക്ഷിക്കുന്നത് നന്നായിരിക്കും.
  4. Browser
    ഈ Web Application പൂര്‍ണമായും പ്രവര്‍ത്തിക്കുന്നത് ഇത് തുറക്കുന്ന ബ്രൗസറിലാണ്. ഇതിന് സെര്‍വര്‍ ഇല്ല. ആയതിനാല്‍ സുരക്ഷിതമായി ഉപയോഗിക്കാം.
  5. ഓഫീസ് പ്രൊഫൈൽ അപ്‌ലോഡ് ചെയ്യുക
    ഇതിനായി Download Sample ബട്ടൺ വഴി മാതൃക JSON ഫയൽ ഡൗൺലോഡ് ചെയ്യുക. ഇത് Notepad ഉപയോഗിച്ച് തുറക്കുക. ഓഫീസ് വിവരങ്ങൾ പൂരിപ്പിച്ച് Upload Profile വഴി upload ചെയ്യുക. വിവരങ്ങള്‍ അടുത്ത വരിയിലേക്ക് വരണമെങ്കില്‍ \n എന്ന് Type ചെയ്യുക. File Upload ചെയ്താല്‍ Profile Active എന്ന് കാണിക്കും.
  6. Logo ചേർക്കുക
    Header ന്റെ കൂടെ Logo ആവശ്യമെങ്കില്‍ Logo upload ചെയ്യാം. Top അല്ലെങ്കിൽ left position തിരഞ്ഞെടുക്കാം. Profile Setting വഴി ചേര്‍ത്ത ഓഫീസ് വിവരങ്ങളുടെ കൂടെ ഹെഡറില്‍ Logo കൂടി കാണാന്‍ പറ്റും.
  7. Header ചേർക്കുക
    ഈ Application ലെ Default Header, Logo Combination ആവശ്യമില്ലെങ്കില്‍ Full Header Image Option തിരഞ്ഞെടുക്കാം. ഇതിനായി JPG/PNG ഫോര്‍മാറ്റിലുള്ള Full Header Image തയ്യാറാക്കി Upload ചെയ്യുക. Header image തയ്യാറാക്കുമ്പോള്‍ Margin ഇല്ലാതെ ശ്രദ്ധിക്കുക. e-Office ല്‍ draft Save ചെയ്യുമ്പോള്‍ Margine വരും.Windows ല്‍ Screen shot എടുക്കുന്നതിനായി Window key + Shift + S ഉപയാഗിക്കാം.
  8. ഡ്രാഫ്റ്റ് തയ്യാറാക്കുക
    Letter, Proceedings, അല്ലെങ്കിൽ Circular/Notice കാർഡ് തുറക്കുക. ഫോം ഫീൽഡുകൾ പൂരിപ്പിക്കുമ്പോൾ വലതുവശത്ത് Preview തത്സമയം കാണാന്‍ സാധിക്കും. തയ്യാറായ കരട് e-Office ലേക്ക് പകര്‍ത്തുന്നതിനായി ഏറ്റവും അടിയിലുള്ള Copy Draft Button ക്ലിക്ക് ചെയ്ത് e-Office ല്‍ Paste ചെയ്യുക. ഇതേ Draft ഭാവിയില്‍ വീണ്ടും ആവശ്യമാണെങ്കില്‍ Download ചെയ്ത് കമ്പ്യൂട്ടറില്‍ സുക്ഷിക്കാം. ഇതിനായി Download Draft Button ല്‍ ക്ലിക്ക് ചെയ്യാം. വീണ്ടും ആവശ്യം വരുന്ന സമയം ആപ്ലിക്കഷനില്‍ മുകള്‍ ഭാഗത്തുള്ള Import Button വഴി Upload ചെയ്ത് edit ചെയ്യാം. ഡ്രാഫ്റ്റുകൾ Save ചെയ്യുമ്പോള്‍ ഫയൽ നമ്പര്‍/തീയതി അടങ്ങിയ Table ഇടതുവശത്തേക്ക് Align ചെയ്തതായി കാണാം. ഇത് ശരിയാക്കുന്നതിനായി save ചെയ്യുന്നതിനു മുമ്പ് Table - ല്‍ ക്ലിക്ക് ചെയ്തശേഷം Table Properties ല്‍ പോയി Width 100% ആക്കുക. Chrome browser-ല്‍ e-Office ല്‍ Draft save ചെയ്യുന്ന സമയത്ത് മറ്റേതെങ്കിലും Alignment issue ഉണ്ടാകുകയാണെങ്കില്‍ Firefox browser ഉപയോഗിക്കുക.
  9. Copy Options
    മുഴുവൻ കരടും പകർത്തേണ്ടില്ലാത്ത അവസരങ്ങളിൽ ആവശ്യമുള്ള ഭാഗം മാത്രം തെരഞ്ഞെടുക്കാം. ഇതിനായി Copy Draft — Include Sections ൽ പോകുക.
  10. Print Preview
    Preveiew Panel ല്‍ കാണുന്ന draft ഉം e-Office ലെ Draft ഉം തമ്മില്‍ ചെറിയ വ്യത്യാസങ്ങള്‍ ഉണ്ടായിരിക്കും. കാരണം രണ്ടിലെയും ഫോണ്ടുകൺ വ്യത്യസ്തമാണ്. Preveiew Panel ല്‍ കാണുന്ന draft ന്റെ Printout ആവശ്യമെങ്കില്‍ പ്രിന്റ് എടുക്കാൻ സാധിക്കും
  11. Excel File Upload
    ഈ ആപ്ലിക്കഷനില്‍ Table ചേര്‍ക്കുന്നത് Excel File മുഖേനയാണ്. ഇതിനായി Excel Sheet - ല്‍ ആവശ്യമായി വിവരങ്ങള്‍ ചേ‍ര്‍ത്ത ശേഷം Upload Excel ബട്ടണ്‍ മുഖേന File Upload ചെയ്യുക Letter/Proceedings/Notice Body യില്‍ cursor point ല്‍ Table Insert ചെയ്തതായി Preview-ല്‍ കാണാം. Table Delete ചെയ്യാനും Edit ചെയ്യാനും Split ചെയ്യാനുമുള്ള Options താഴെ നൽകിയിട്ടുണ്ട്.
  12. Manage Address button ഉപയോഗിച്ച് To Address ചേര്‍ക്കാം. ഈ വിവരങ്ങള്‍ Store ചെയ്യുന്നത് ബ്രൗസറിലാണ്.
  13. Mail Merge
    Template ഉപയോഗിച്ച് ഡ്രാഫ്റ്റുകൾ തയ്യാറാക്കാൻ ഈ Mail Merge ഉപയോഗിക്കാം. ഇതിനായി ആദ്യം Template തയ്യാറാക്കുക. Template ല്‍ പൂരിപ്പിക്കാനാവശ്യമായ വിവരങ്ങള്‍ Excel Sheet ൽ തയ്യാറാക്കുക. Google Sheet ൽ തയ്യാറാക്കുന്നതാണ് നല്ലത്. ശേഷം excel/CSV ഫയൽ Download ചെയ്യുക. ഈ ഫയൽ അപ്‌ലോഡ് ചെയ്യുക. ഓരോ കോളം ഹെ‍ഡറിനു മുകളിലും {} നുള്ളില്‍ Placeholder കാണാം ഇതില്‍ ക്ലിക്ക് ചെയ്ത് കോപ്പി ചെയ്ത് Template ല്‍ ആവശ്യാമായ സ്ഥലങ്ങളിൽ Paste ചെയ്യുക. ശേഷം Next Button ക്ലിക്ക് ചെയ്യുക. അപ്പോള്‍ Placeholder ന്റെ സ്ഥലത്ത് യഥാ‍ര്‍ത്ഥ Table value വരുന്നതായി കാണാം. ഇപ്രകാരം ഓരോ excel/csv വരികളിലേയും data Template ലേക്ക് വരുന്നതിനായി Next Button Click ചെയ്യുക. ഓരോ ഡ്രാഫ്റ്റും Copy ചെയ്ത് e-Office ല്‍ പേസ്റ്റ് ചെയ്യുക.
  14. Mail Merge ലെ മുഴുവന്‍ കരടുകളും ഒരുമിച്ച് PDF ആയി കാണാന്‍ 📄 All Drafts ബട്ടണിൽ click ചെയ്യുക
  15. Upload Data Sheet to Preview
    Preview Panel ൽ വലതു വശത്തായി 'Upload Data Sheet' എന്ന ബട്ടണ്‍ കാണാം. ഇത് വഴി Excel File/csv Upload ചെയ്യാം. ഇവിടെ Upload ചെയ്യപ്പെട്ട Excel Sheetnz മുഴുവൻ Tab കളും ഇവിടെ കാണാം. ഈ Data ഒരു ക്ലിക്കിലൂടെ cursor point ലേക്ക് Copy Past ചെയ്യാം. കൂടാതെ Excel Sheet ലെ വിവരങ്ങൾ Search ചെയ്യാനും സാധിക്കും.
